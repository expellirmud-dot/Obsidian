# Archive Index

## โฟลเดอร์นี้ใช้เก็บอะไร

เอกสารเก่าที่เลิกใช้งานแล้ว แต่ต้องเก็บไว้เป็นหลักฐานและประวัติ

## สิ่งใดควรเก็บ

- เอกสารที่ถูกแทนที่ด้วยฉบับใหม่
- Work Order / ADR / หน้าโปรเจกต์เวอร์ชันเก่าที่ปิดไปแล้ว
- บันทึกที่หมดอายุการใช้งานแต่ยังมีคุณค่าทางประวัติ

## สิ่งใดไม่ควรเก็บ

- ห้ามใช้ Archive เป็นถังขยะ — เอกสารไร้คุณค่าจริง ๆ ให้ Owner ตัดสินใจลบเอง
- Secret หรือ Credential (แม้ในเอกสารเก่า)
