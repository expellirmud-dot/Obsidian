# Lessons Learned Index

## โฟลเดอร์นี้ใช้เก็บอะไร

บทเรียนจากเหตุการณ์จริง — สิ่งที่คาดไว้ สิ่งที่เกิดขึ้นจริง สาเหตุ และการป้องกันการเกิดซ้ำ

## สิ่งใดควรเก็บ

- เหตุการณ์ที่ผลลัพธ์ต่างจากที่คาด พร้อม root cause ที่ตรวจสอบแล้ว
- มาตรการป้องกันการเกิดซ้ำ
- หลักฐานอ้างอิง (commit, log, Work Order)

## สิ่งใดไม่ควรเก็บ

- การคาดเดาสาเหตุที่ยังไม่ได้ตรวจสอบ
- คำตำหนิบุคคล — โฟกัสที่กระบวนการ
- Secret หรือ Credential ใน log ที่แนบ
