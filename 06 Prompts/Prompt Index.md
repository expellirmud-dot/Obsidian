# Prompt Index

## โฟลเดอร์นี้ใช้เก็บอะไร

Prompt ที่ใช้ซ้ำได้ และ Templates สำหรับสร้างเอกสารมาตรฐานใน Vault

## สิ่งใดควรเก็บ

- Template เอกสารมาตรฐาน (Project, Decision, Lesson, Resume Context)
- Prompt สำหรับสั่งงาน AI ที่พิสูจน์แล้วว่าใช้ได้ผล
- คำอธิบายบริบทการใช้ Prompt แต่ละตัว

## สิ่งใดไม่ควรเก็บ

- Prompt ที่ฝัง Secret, Token หรือข้อมูลส่วนบุคคล
- Prompt ที่ผูกกับสถานะชั่วคราวซึ่งล้าสมัยเร็ว

## รูปแบบการตั้งชื่อไฟล์

- Template: `<Purpose> Template.md` ในโฟลเดอร์ `Templates`
- Prompt: ชื่อที่มนุษย์อ่านเข้าใจได้ สื่อวัตถุประสงค์
